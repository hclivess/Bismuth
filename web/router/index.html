Bismuth Router — one contract, many BIS-paired pools, any token ⇄ any token (VM demo)

A multi-pool constant-product AMM. Every token has its own BIS pool; a token→token swap routes A→BIS→B atomically in one call (no cross-contract calls exist on this VM, so all pools live in one "vault" contract). The 0.3% fee is taken on each hop and stays in the pools — that is the LPs' yield. Demo caps: ≤16 tokens, each reserve ≤ ~10.7 BIS, 24-bit address fold (see doc/24 §3).
